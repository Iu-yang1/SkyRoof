# SkyRoof SSTV 收发控制台（开发预览）

> **尚未作为正式版发布。** 此文档适用于 [PR #130](https://github.com/Iu-yang1/SkyRoof/pull/130) 的开发分支，不表示已完成 IC-9700 实机验收或 MMSSTV 全功能兼容。

## 使用界面

在 **视图 → SSTV RX / TX** 中打开独立的 SSTV 工作区。包含 **接收 RX、发送 TX、图库 / 历史、通联日志** 四个标签，支持停靠或浮动显示。

### 接收与自动校频

选择声卡 AF、RS-BA1 播放设备回环、12 kHz 实数 IF 输入或 IF 回环，点击 **开始接收**。Robot 36/72 和 PD 家族保留现有 SkySignals 解码器；其他 RGB、扩展与窄带模式使用新建的 VIS 识别及逐行解码链。

**自动校频** 默认开启，通过完整 VIS 导频、同步、数据位及校验后估计相对 AF 频偏并修正音频。扩展模式与 Robot/PD 接收链均已加入逐行水平同步音残余频偏跟踪。**校频 Hz** 可手动设定 ±500 Hz，并在 VIS 识别及图像解码前统一应用，便于校正卫星较大的音频偏移。这些功能不会自动修改上行 CAT、卫星转发器基频或已保存的多普勒偏移。

卫星信号弱到无法收到 VIS 时，可以选定具体接收模式，并在图片开始时点击 **手动开始**。**导入 WAV** 支持 48 kHz、16-bit、单声道音频；可自动识别标准 VIS、16 位扩展 VIS、24 位窄带 N-VIS，或由操作者手动指定模式。解码后的图片和 UTC 元数据可保存至 `SstvImages` 文件夹。**图像倾斜**可为导入的 RGB/扩展/窄带 WAV 手动修正 ±1000 ppm 采样时钟偏差，目前不是实时自动斜率校准。若接收到校验通过的 MMSSTV FSK 台站标识，导入 WAV 及实时 AF/IF 接收均可将呼号作为提示，供人工核实；不会自动建立 QSO。

**注意：** 算法已具备自动识别及逐行处理路径，不等于所有模式在 AWGN、QSB、多径、时钟斜率以及卫星多普勒下均已完成独立验证。RS-BA1 回环采集的是整个 Windows 播放设备，不单独隔离 RS-BA1 进程，建议分配独立音频设备。

### 发送图片与模板

可打开或粘贴图片，按选定模式的画幅比例居中裁剪、旋转、镜像、撤销和重做。模板包括 **经典呼号、QSL 卡片、卫星横幅、纯图片**，可另存自定义模板。文字支持 `{CALL}`、`{MYGRID}`、`{HISCALL}`、`{SAT}`、`{MODE}`、`{UTC}`、`{DATE}`、`{TXHZ}`、`{RXHZ}` 等宏。

发送编码路径目前包含 MMSSTV 的 **43 个模式**：Robot、PD、Scottie、Martin、SC2、P3/P5/P7、MP/MR/ML、MP-N/MC-N。分别生成 8 位 VIS、16 位扩展 VIS 或 24 位 N-VIS，输出 48 kHz 单声道 WAV。**保存音频 WAV** 不触发电台 PTT，适合离线验证；界面的发射声卡/PTT 功能仍是实验性代码。

### 通联日志

收到 SSTV 图片不代表自动建立 QSO。请在 **通联日志** 标签手动填写对方呼号，核对 UTC、卫星及 TX/RX 频率后保存。可将接收图片与日志关联，并导出 ADIF。仅收到图片或解出 FSK 标识并不自动记为完成通联。

## CAT/PTT 发射保护

实验性发射路径需要操作者确认上行频率/功率、选择实际的音频输出端、选择处于地平线以上且有有效 2m/70cm 业余上行的卫星，并在 CAT 确认发射频率、PTT 所有权与实际读回之后发射。程序会持续检查卫星位置、频率、多普勒、上行模式与连接状态；用户点击 **停止发射** 或发生超时、失联、错误时请求解除自己持有的 PTT。发射结束时须收到新的 CAT PTT OFF 硬件读回才会提示成功；如未确认，会锁存故障并禁止再次发射，要求操作者检查电台。

**这不意味着发射已通过实机验收。** 必须在 IC-9700 上使用假负载、低功率和独立频谱/接收监测，检查 RS-BA1/USB/LAN 音频注入、音量、频谱纯净度、长时间多普勒、PTT OFF、断网及软件异常。CAT 返回 PTT OFF 不是射频功率确实消失的独立证据。

## 全功能验收仍存在缺口

目前 43 个模式的发送编码与接收解码路径已经提交，但**还未逐模式用独立 MMSSTV 参考录音完成交叉验证**。剩余工作包括实时自动时钟斜率/相位与采样率校准、全部滤波/抗噪设置、实时 CW/FSK ID 的充分验收、旧版转发器/竞赛/QSL/COM/OLE 功能的等效实现或替代，以及实际 IC-9700 发射停机试验。不得将单元测试全部通过等同于真实电台兼容性、接收灵敏度和射频安全验收完成。
