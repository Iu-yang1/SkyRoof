# SkyRoof SSTV 收发控制台

在 **视图 → SSTV RX / TX** 中打开可停靠的 SSTV 控制台，包含接收、发射、图库和通联日志。

## 接收

支持声卡 AF、RS-BA1 播放回环、12 kHz IF 和 IF 回环。**接收模式**中列出与 TX 完全相同的 43 种 SSTV 制式，另外提供“自动识别 SSTV”。Robot/PD 由原有 SkySignals 解码器自动识别；Scottie/Martin/SC2 和扩展模式可选择“手动开始”以辅助弱 VIS 信号。手动选择 Robot/PD 时不强制启动扩展解码器，而是等待原生 VIS 检测。

可调整校频 Hz、自动校频与图像倾斜，也可导入 WAV、保存图片或查看历史。

## 图库管理与 AF/IF 音调刻度

图库／历史页提供**导入图片、导出选中图片、删除选中图片**，支持从外部图片导入 PNG/JPG/BMP/GIF 并统一存为 PNG；删除前会确认，同时清理该图片对应的接收元数据。点击 TX 底部已存在的缩略图，只切换发送图片，不会向最近图片列表添加重复项；右键可打开操作菜单。

RX 和 TX 共享同一款橙色加黑色 MMSSTV 风格音调参考条，顶部只标出 **1200、1500、1900、2300 Hz** 四个数字。RX 黑色区域同时显示实时 AF/IF 音调频谱，TX 下方黑色区域保持空白；两者频率刻度和尺寸绘制方式完全一致。

## MMSSTV 风格 TX 布局

发送页采用上方图片操作工具条、左侧大幅图片预览、右侧纵向 43 模式快捷选择和 QSO 信息、底部近期图片/接收记录缩略图库的分区设计。缩略图可点击复用；模式列表与下拉选择保持同步。右侧橙色条为 **AF 频率刻度参考**（1200/1500/1900/2300 Hz），不是实时发送频谱。窗口较小时可滚动右侧的 QSO、文字样式与音频设置。

QSO 信息提供 MY/HIS 呼号、发射及接收 RST、姓名、QTH、备注和可编辑的图片文字。保存通联后 RST、姓名、QTH 可随日志导出 ADIF。

## 多图层文字与 RSV 变量

TX 的“图片文字样式”可使用 **新增、复制、删除** 管理最多八个独立图层（己方呼号、对方呼号、默认文字三个基础图层及五个附加图层）。每层均能分别编辑内容、文字颜色、字号、拖动位置，也能复制现有呼号图层继续放置。变量下拉框提供插入按钮，支持 `{MYCALL}`、`{HISCALL}`、`{MYGRID}`、`{SAT}`、`{MODE}`、`{RSV_TX}`、`{RSV_RX}`、`{NAME}`、`{QTH}`、`{NOTE}`、`{UTC}`、`{DATE}`、`{HHMMSS}`、`{TXMHZ}`、`{RXMHZ}` 等。旧模板里的 `RST_TX`、`RST_RX` 变量仍兼容。

TX 通联信号报告标签使用 RSV；导出 ADIF 仍填写标准 `RST_SENT` 和 `RST_RCVD` 字段。模板文件兼容旧三图层格式，新附加图层会一起保存和恢复。

性能方面，外部大图在载入编辑器前缩放到合理尺寸；图库缩略图复用缓存，撤销/重做复用位图，已接收的 PNG 图片保存可直接复制，并减少高频拖动时的插值开销。

## 发送和图片文字编辑

1. 打开或粘贴图片，选择 SSTV 模式、内置模板或自定义模板。
2. 分别填写 **己方呼号**、**对方呼号**，以及可选的 **自定义文字**。自定义文字支持 `{CALL}`、`{MYGRID}`、`{HISCALL}`、`{SAT}`、`{MODE}`、`{UTC}`、`{DATE}`、`{TXHZ}`、`{RXHZ}` 等宏。
3. 在“编辑对象”中选择己方呼号、对方呼号或自定义文字，分别设置 **字号 %** 和 **文字颜色**。在预览图中用鼠标左键**拖动文字**改变位置；悬停在预览区使用滚轮调整当前图层大小。
4. 所有位置按图片宽高的归一化比例保存，因此更换 Robot、PD、Scottie 或宽幅 SSTV 模式后仍会按相对位置布局。
5. “保存模板”保留三层文字内容、颜色、字号、位置及背景风格；选中个人已保存模板后点“删除模板”即可删除。内置的经典呼号、QSL 卡片、卫星横幅与纯图片为固定预设，不允许删除。
6. “保存音频 WAV”离线导出 48 kHz 单声道 SSTV；发射操作需指定音频输出设备，按“停止发射”或 Esc 可以停止。

纯图片预设不绘制文字叠加。自定义模板沿用 `SstvImages/templates.json`，旧版文件可直接读取；删除一个模板不会清除其他模板或原始图片。

## 通联日志

手动录入对方呼号、UTC 时间、卫星、模式、上下行频率及图片备注，支持 ADIF 导出。可选 CW/FSK 台站识别按己方呼号输入框输出。

## 测试与开发记录

当前代码覆盖 43 种 TX 模式及接收识别链。Windows CI 对 UI、图片与模板编辑、模式列表、虚拟 CAT/PTT、音频编码等进行软件测试，代码更新见 [仓库 PR](https://github.com/Iu-yang1/SkyRoof/pulls)。接收中的部分扩展制式仍可能受同步、衰落或样本时钟误差影响。
