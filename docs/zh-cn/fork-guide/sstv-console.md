# SSTV 收发控制台（开发预览）

> **尚未正式发布。** 此功能位于 [SkyRoof PR #130](https://github.com/Iu-yang1/SkyRoof/pull/130)，不代表 MMSSTV 全模式兼容或 IC-9700 实机发射验收。

在 SkyRoof 的“视图”菜单中打开 **SSTV RX / TX**，可在接收、发送、图库三个标签之间切换。

## 接收与解码

1. 选择声卡 AF、RS-BA1 播放设备回环或真实 **12 kHz IF** 输入；确保音频设备实际传送的是电台接收信号。
2. 点击 **开始接收**。对于整体偏移的音频，使用 ±500 Hz 的“校频 Hz”手动修正；这只是音频频移，不会修改电台 CAT 频率。
3. 解码完成后图片与 UTC 元数据保存至 SkyRoof 用户数据目录的 `SstvImages` 文件夹，可在 **图库 / 历史** 中查看。
4. **导入 WAV** 可以解码 48 kHz / 16-bit / 单声道、最长 7 分钟的录音。

目前自动解码能力来自 SkySignals：Robot 36/72，以及 PD 50/90/120/160/180/240/290。其他 MMSSTV 模式尚未完成。

回环录音采集 Windows 对应播放设备的全部混音，不是只捕捉 RS-BA1。建议将 RS-BA1 音频分配至独立设备，以免混入系统声音。

## 制作与导出图片

在 **发送 TX** 页面可以打开/粘贴图片，选择已支持的模式，并覆盖呼号或简短文字。点击 **保存音频 WAV** 可在不触发 PTT 的情况下生成带 VIS 的 SSTV 音频，便于核对波形。

## 实验性发射注意事项

开发分支已加入选择发射声卡、**已确认频率 / 功率**、**发射图片**与**停止发射**。执行 PTT 之前会核对卫星当前可见、上行模式为 USB/FM、2m/70cm 业余频段、实际 CAT 发射频率读回以及音频输出设备。随后等待硬件 PTT 读回并持续监视上行频率与卫星状态。

如发生 CAT/PTT 失联、频率不符、卫星位置失效、声卡失败、超时或点击停止，程序请求释放自身发起的 PTT。卫星多普勒不会因长时间发送而被整体冻结。

**实际使用之前必须做 IC-9700 假负载测试：** 核对电台发射音频输入口、MODE、USB/FM、功率、PTT OFF、频谱与驻波；测试故障时的停止行为。CAT 显示发射不等于已验证射频输出；也不能把丢失 CAT 应答当成已经解除 PTT。

## 尚未完成的功能

Martin、Scottie、AVT、SC2、P3/P5/P7、MP/MR/ML、窄带扩展 VIS/N-VIS 的完整收发，以及 MMSSTV 模板/宏/QSO 日志功能、真正由 VIS/同步脉冲驱动的 SSTV 自动 AFC、IC-9700 实机验证和正式版验收，均仍待实现。

因此本页面仅为开发预览文档，不能作为稳定版发布说明。具体开发门槛见 [SSTV 集成矩阵](../../architecture/sstv-console-integration-plan.md)。
