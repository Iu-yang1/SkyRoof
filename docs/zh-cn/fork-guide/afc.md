# FM / CW / SSB 多普勒辅助 AFC

**语言：** [English](../../fork-guide/afc.md) | 简体中文

AFC 使用单独的 12 kHz IF PCM 输入，在 SkyRoof 原有卫星多普勒与人工
调谐结果上叠加**临时 RX 修正量**，不修改转发器频率、永久手动修正、
RIT/XIT 或 TX 上行频率。有关 IC-9700 USB/LAN 12 kHz IF 输出，见
[Icom 官方说明书](https://icomuk.co.uk/files/icom/PDF/productManual/IC-9700_ENG_Basic_6.pdf)。

## AFC 自动方向校准与 CAT 闭环保护（v1.60）

- 当 AFC 为 Auto 且 RF/IF 方向设为 0 时，只有在稳定的真实 12 kHz IF 参考、时间对齐的 CAT RX 读回均满足要求后，才会开始 RX-only 方向校准。
- 方向校准使用一组受控的 RX CAT 调谐及恢复：FM 默认 150 Hz，CW/有导频 SSB 默认 40 Hz，实际幅度按 CAT 调谐步进取整。两个方向的调谐必须分别获得硬件读回和至少两次已稳定的 IF 频偏测量；回到原始接收频率且方向一致后，才能开放 Auto AFC。
- 对持续跟踪卫星的 CAT 位移先扣除卫星模型预测的多普勒频率变化，避免将正常卫星运动误认为校准异常。
- 调谐的 CAT 请求不能充当硬件读回确认；CAT 读回必须发生在本次校准步骤下发之后，且 IF 测量窗口必须位于生效后的时间段。失败信息将说明调谐或恢复阶段的超时原因。
- 校准阶段只叠加临时 RX 偏移，不修改卫星模型、上下行手动修正、RIT/XIT 或 TX。失号、PTT、超时、卫星切换、模式变化或操作者调谐时撤销偏移；验证失败禁止自动写频，需重新捕获/初始化。
- 若 CAT 设置启用 `Ignore Dial Knob`，AFC 仍可在接收时使用实际 CAT 频率读回，但不会把人工旋钮反馈当作软件调谐。
- 控制页面会显示 CAT 的真实读回年龄与校准阶段；「信号已锁定」不等于「已通过 RF/IF 方向验证」。不要在没有实际测试的情况下手动猜测正负方向。

## 本次 P1–P4 更新的操作界面

AFC 已改为两个页签：**实时追踪**与**高级设置**。实时追踪页显示
12 kHz IF 的实际 FFT 频谱、观测频偏、目标误差、RX AFC 修正量、
置信度、CAT 状态、RF/IF 方向及故障原因。点击频谱可选择 CW/SSB
参考信号；FM 的中心频率估计不需要点击单音目标。

**锁定当前**以当前被选信号频率为基准保留其音调，
**居中并锁定**则试图将该信号调至高级设置中的
`Desired center IF offset (Hz)`。它与用来搜索原始信号的
`Target search IF offset (Hz)` **是两个独立参数**，不能混用。
若显示 `Fault`，应检查真实 IF/CAT 响应并重新选择目标，
不能让后台自动反向追频。

普通目标参数更新不会重启音频设备；只有切换输入设备、输入方式
或 IF 参考频率才需要重新启动采集。切换卫星/转发器或修改 IF
目标时，旧 PCM 和 AFC 目标身份会失效并重新捕获。

CAT 读回按照它在 CAT 工作线程的实际时间保存，只允许与
对应样本时刻相近的 IF 观测配对，过期的读回不会参与自动方向
学习。写频请求和真实设备读回分开记录，不能把「已请求」当作
「已确认」。

## 新版 UI 与 RX AFC 快捷开关

AFC「实时追踪」页不再使用固定的 GitHub Dark 背景，而是根据 SkyRoof
启动时的 System / Light / Dark / GitHub Light / GitHub Dark 主题选择
文字、图表、按钮、边框及设置页配色。频谱仍为**真实 IF PCM FFT 结果**，
不使用设计稿中的示意曲线。三项指标是实际下行预测多普勒、测得残余偏差与
当前 AFC RX 修正值，不能把锁定状态误读为 CAT 已经写频。

Frequency Control 在上行 Manual 下方增加 **RX AFC** 复选框，
该选项的位置仅为保持原控制条的紧凑布局，**其作用仅限 RX**。
勾选时，在接收 CAT 与 IF 来源有效、模式支持 Auto 的前提下，
启动 IF 采集并将控制等级切换到 Auto。需要真实参考导频的
SSB 模式在未启用导频时不能自动启动，以免无参考追频。
取消勾选时停止 Auto，打开的弹窗退回 Assist；如果只是
后台打开的 AFC，则停止 IF 并销毁后台窗口。
勾选 RX AFC 后手动关闭 AFC 窗口只会隐藏窗口，
**不会关闭后台自动 AFC**；再次从下行频率右键或者双击可重新打开。
原先的 AFC 入口和手动「关闭 / 辅助 / 自动」切换均保留。

首次使用需在高级设置中指定有效 12 kHz IF 输入设备。
未确认 CAT、没有可识别的信号或 RF/IF 方向未学到时，Auto 请求
不等于允许写频；必须以实际状态、置信度和硬件读回为准。

## IF 频谱重构（P0–P4）

AFC 窗口的频谱改为 **12 kHz IF 显示专用 DSP**：复用
\`CwRealFft\`/FFTW3f，从原有 \`AfcIfInput\` 的 48-kHz PCM 缓冲中
独立读取 8192 点，目标约每 65 ms 更新一帧（实际速率取决于设备
输入批大小、CPU 与 WinForms 调度）。原 AFC 频偏估计、时间戳配对、
PTT 冻结及 CAT 闭环仍保留约 550 ms 控制采样周期，**显示处理绝不回写
AfcController**。

上方频谱采用稳定的显示参考等级，不再对每帧最大峰值
强制归一化至 0 dB；按屏幕像素保留区间内最大频谱峰，防止
窄 CW 信号在绘图降采样中消失。下方可选 180 帧环形瀑布图，
不在每次绘制时逐像素重建整幅缓存。显示模式支持：

- **SPAN**：12 / 6 / 2 / 1 kHz；鼠标滚轮缩放，右键恢复 12 kHz。
- **AVG**：关闭 / 100 / 200 / 400 ms，按线性功率计算 EMA 后转为 dB。
- **PEAK**：峰值保持。
- **WF**：显示/隐藏与频谱共用频率轴的瀑布图。
- **HALO**：显示用局部噪声基线展平。CW 可启用，FM 宽带信号
  建议关闭，以免改变真实调制包络的视觉形状。
- **BH4**：四项 Blackman–Harris 窗；关闭则使用 Hann 窗。

频谱与瀑布图现在复用 SkyRoof Icom LAN Scope 的 **RS-BA1 Classic 161 级色阶**：
深蓝仪表背景、绿色信号谱线、黄色峰值/中心标记，以及由蓝、青、绿、
黄到白色的瀑布图信号等级。各种 SkyRoof Light/Dark/GitHub/System
主题下，仪表区域均保留深蓝基底，周围控件遵循应用主题。

**高级设置 → IF 频谱 REF LEVEL (dB)** 默认 **+15 dB**，会随
AFC 设置持久保存。调高数值使信号显示变暗，调低有助于观察弱信号。
REF 仅调整频谱/瀑布图的显示范围，不改变 AFC 频偏估计及 CAT 控制。

Y 轴只是便于观察的 dB 显示刻度，**未经硬件绝对功率标定**，
不能将其当成真实 dBm。状态栏提供 IF PCM RMS 与削波比例，用于判断设备是否确实输入、
电平过高或信号过低；采集已启动不代表 RF 参考有效。

频谱点选 CW/SSB 导频的控制逻辑不变。后台勾选 RX AFC 而隐藏
窗口时会关闭显示 FFT 调度，但不停止接收 IF 和 AFC 自动控制。
卫星/转发器改变、音频流代际更新会丢弃旧的频谱历史，不能跨目标
拼接瀑布图或沿用旧测量样本。

## FM IF 有频谱、没有频偏读数的诊断

AFC 的 IF 频谱使用约 8192 点 PCM，频率测量至少需要 24000 点 PCM；两者独立运行。如果音频设备连续回调的时间戳相同，旧版可能错误地清空频偏测量缓冲，导致频谱和瀑布图有信号，但置信度维持 0% 且残余频偏看起来是 0 Hz。本版接受重复时间戳并以 PCM 样本量推进测量时钟，仅在原始设备时间戳真实倒退时重新建代。

新版实时追踪会提示 **等待 IF PCM、等待测量调度、测量执行情况、测量失败**。如果 FM 的原始 IF 偏移已得到数值但质量不足以参与自动校频，会显示 **候选频偏** 与测量质量，并保持 CAT 自动修正关闭。**没有测量时不再显示 0 Hz 残余频偏**。

FM 的原始频率估计来自相位鉴频和多时间窗统计，频谱中最强峰的频率不一定是调制后的 FM 载波中心。检查频率时可在有已知静噪载波或稳定 FM 信号的条件下比较测量偏移；RF/IF 方向未校准不会禁止只读测量，但会限制自动 CAT 调谐。

## 使用步骤

1. 在 IC-9700 设置 `SET > Connectors > USB AF/IF Output >
   Output Select > IF`。选择承载 IF 的 USB 声卡输入。
   **12 kHz 是实际模拟中频，不是采样率或复数 IQ。**
2. 在 SkyRoof 的**下行频率文字上右键**，打开 **FM / CW / SSB AFC...**，
   或双击下行频率。选择正确的 Windows IF 采集设备，点 **Start IF**。
   对于远程 IF 可将 **IF transport** 改为 **PlaybackLoopback**，
   选择真正输出 12 kHz IF 的远程播放设备，而不是普通 AF 音频。
3. **Assist**：只读频率观测，不改变 CAT。**Auto**：有可靠观测和
   有效频率方向时允许仅对 RX 进行自动补偿；未确认方向不会盲目写频。
   不要求每次打开软件都重新进行人工标定。
4. CW：在「实时追踪」频谱上直接点击目标信号，或在「高级设置」
   的 **Target search IF offset (Hz)** 中填写要搜索的原始频偏。
   **锁定当前**保留该信号当前 IF 音调；**居中并锁定**将其向
   **Desired center IF offset (Hz)** 指定的中心位置移动。
   多台 CW 信号互相靠近时，若界面报告歧义应重新选择目标。
5. SSB：普通抑制载波话音无法唯一确定绝对频率。只有实际存在稳定
   导频/CW 信标时，才开启 **SSB reference available** 并允许 Auto。
   无参考时保持 Assist。

## 数据通道和安全规则

- **CI-V 27 00 频谱不是 IQ**，不能作为该 AFC 的 IF 输入。
- Windows WASAPI 输入使用 48 kS/s 实数 PCM，再数字下变频、
  FIR 滤波和抽取为复数基带。
- 原 CW Console 需要的是**解调 AF 音频**；若 USB 被设置为 IF，
  CW 解码应改用独立的 AF 通路，例如正确配置的 RS-BA1 播放回环。
- Icom 手册确定了 12 kHz IF 输出，但未给出所有模式及滤波设置下
  一致的 IF/CAT 频率方向。将 **RF/IF direction = 0** 保持默认时，
  AFC 会尝试从已锁定信号及 CAT 调谐读回的相对位移自动推断。
  `+1`、`-1` 只用于已确认的频率映射。
- 仅由现有 SkyRoof/SkyCAT CAT 控制链调谐 RX，AFC 不另建第二个
  远程控制会话，不修改 TX。
- PTT、音频时间线改变、模式切换和信号丢失会冻结或重置 AFC
  更新。频率方向未确认时不执行自动 CAT 修正。

## 模式能力

| 模式 | 频率估计 | 当前策略 |
|---|---|---|
| FM | 多时间窗鉴频均值、稳定性和置信度 | 间歇 FM 失号保持，低速修正 RX |
| CW | IF 窄带 FFT 与峰值插值 | 跟随所选 IF 频点，不随意改为最强台 |
| SSB | 明确的稳定参考音频峰 | 有参考可 Auto，无参考仅 Assist |

## 验证边界

仓库提供合成 IF 的 xUnit 测试，覆盖 CW 音调、SSB 无载波、
RF/IF 频率方向未知、信号失效、PTT 以及音频源代次切换。
**这些测试并不等于 IC-9700/IC-705 实机验收**。如需定量证明
不同固件与滤波带宽的表现，需要录制已知 RF 输入、12 kHz IF
PCM，以及同时刻的 CI-V RX 频率读回。
